🔧 HOW THE AUTO-DETECTION WORKS
═════════════════════════════════════════════════════════════════════════════════

Step 1: User runs any script in ai/
        ↓
Step 2: Auto-detection activated
        ├─ Check if s6-eth1 exists → YES? Use it! ✅
        ├─ Check if s6-eth4 exists → YES? Use as fallback
        ├─ Check if h82-eth1 exists → YES? Use as fallback
        └─ DEFAULT: Use "s6-eth1" (will fail gracefully if not in network)
        
Step 3: Script runs on selected interface
        ├─ Captures flows with proper filtering
        ├─ Preserves IP addresses (no SNAT)
        └─ Outputs to zeek_stream.json (FIFO)
        
Step 4: auto_dataset_generator.py processes
        ├─ Reads from zeek_stream.json
        ├─ Applies bidirectional filter (REQUEST + RESPONSE)
        ├─ Classifies attacks using classify_flow()
        └─ Writes to master_dataset_v6.csv
