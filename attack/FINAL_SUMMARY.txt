📞 TROUBLESHOOTING:
───────────────────────────────────────────────────────────────────────────────

Q: "ModuleNotFoundError: No module named 'dotenv'"
A: pip install python-dotenv

Q: ".env file not found"
A: cp .env.example .env

Q: "Port CLOSED"
A: Thử port khác, check firewall

Q: "Ping failed"
A: Kiểm tra IP đúng không, ping 8.8.8.8

Q: "Permission denied"
A: sudo python3 attack_script.py
